# Personal Portfolio — Aryan Acharya

This is my personal portfolio website, created to introduce myself, showcase my technical skills, projects, education, experience, and a few things I enjoy outside of coding.

I built this portfolio as a place where I can bring everything together in one simple and professional website instead of relying only on a traditional resume. It represents me as a Computer Science and Engineering student who enjoys problem-solving, web development, and exploring new technologies.

### What you'll find here

- A short introduction about me
- My technical skills and technologies I work with
- Projects I have worked on
- My internship experience at NALCO
- My educational background
- Certifications and achievements
- My interests outside of technology, including Tabla and Cricket
- Contact information and LinkedIn profile

### Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Google Fonts

The website is designed with a dark, modern interface and responsive layout so that it works across desktops, tablets, and mobile devices. I also added small animations and interactive elements to make the experience feel more dynamic without making the website unnecessarily complicated.

### Why I Built It

I wanted to have a personal space on the web that I can continuously improve as I learn and gain more experience. This portfolio is not meant to be a final version — I plan to keep adding new projects, skills, experiences, and improvements as my journey in technology continues.

I'm currently pursuing my B.Tech in Computer Science and Engineering and am particularly interested in software development, web technologies, problem-solving, and emerging areas such as Artificial Intelligence.
